# LACRELADORA 🧮

Calculadora multifuncional feita em [Flowgorithm](https://flowgorithm.org/), com 10 operações matemáticas.

## Como usar

1. Baixe e instale o [Flowgorithm](https://www.flowgorithm.org/download/index.htm) (gratuito).
2. Abra o arquivo `LACRELADORA.fprg` no programa.
3. Clique no botão **Run** (▶) ou pressione **F5**.
4. Digite o número da operação desejada e siga as instruções na tela.

## Operações disponíveis

| Opção | Operação |
|---|---|
| 1 | Soma |
| 2 | Subtração |
| 3 | Multiplicação |
| 4 | Divisão |
| 5 | Potenciação |
| 6 | Raiz quadrada |
| 7 | Área do círculo |
| 8 | Área do retângulo |
| 9 | Celsius para Fahrenheit |
| 10 | Média aritmética |
| 11 | Encerrar o programa |

## Exemplo

```
Escolha uma opção de 1 à 11: 1
digite o primeiro numero: 10
digite o segundo numero: 5
Resultado: 10 + 5 = 15
```
